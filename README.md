### [Smart Alumni Connect & Job Referral System](https://github.com/omteja04/alumniconnect)
> <img src="https://img.shields.io/badge/react-%2320232a.svg?style=flat-square&logo=react&logoColor=%2361DAFB"> <img src="https://img.shields.io/badge/node.js-6DA55F?style=flat-square&logo=node.js&logoColor=white"> <img src="https://img.shields.io/badge/AWS-%23FF9900.svg?style=flat-square&logo=amazon-aws&logoColor=white"> <img src="https://img.shields.io/badge/ServiceNow-%23005A61.svg?style=flat-square&logo=ServiceNow&logoColor=white">

- Designed and implemented a serverless integration layer connecting ServiceNow workflows with a React-based frontend for managing job referrals and alumni engagement.
- Developed backend services using Node.js APIs to automate referral tracking, workflow updates, and cross-system data synchronization.
- Implemented secure identity management using AWS Cognito, supporting authentication, authorization, and role-based access control.
- Built scalable APIs enabling real-time status updates and automated referral processing across the system.
- Designed the system architecture to support scalable alumni-network interactions and enterprise workflow integrations.

### [Artzen – AI Text-to-Image SaaS Application](https://github.com/omteja04/artzen) | [Live App](https://artzen.vercel.app/)
> <img src="https://img.shields.io/badge/react-%2320232a.svg?style=flat-square&logo=react&logoColor=%2361DAFB"> <img src="https://img.shields.io/badge/node.js-6DA55F?style=flat-square&logo=node.js&logoColor=white"> <img src="https://img.shields.io/badge/MongoDB-%234ea94b.svg?style=flat-square&logo=mongodb&logoColor=white"> <img src="https://img.shields.io/badge/tailwindcss-%2338B2AC.svg?style=flat-square&logo=tailwind-css&logoColor=white">

- Built a full-stack MERN AI SaaS application that generates images from text prompts using AI models.
- Implemented JWT-based authentication and secure user session management.
- Integrated Razorpay payment gateway for subscription-based SaaS monetization.
- Designed and implemented REST APIs for prompt submission, image generation, and user management.
- Developed a responsive frontend using Tailwind CSS, ensuring consistent user experience across devices.
- Structured MongoDB collections to efficiently store user prompts, generated images, and transaction data.

### [Serverless URL Shortener](https://github.com/omteja04/levi) | [Live App](https://omteja04.github.io/levi/)
> <img src="https://img.shields.io/badge/AWS-%23FF9900.svg?style=flat-square&logo=amazon-aws&logoColor=white"> <img src="https://img.shields.io/badge/javascript-%23323330.svg?style=flat-square&logo=javascript&logoColor=%23F7DF1E">

- Designed and implemented a fully serverless URL shortening service using AWS Lambda, DynamoDB, and API Gateway.
- Created REST endpoints for short URL generation and redirection with minimal latency.
- Designed a DynamoDB schema using short code as the partition key enabling O(1) URL lookup.
- Built a system capable of handling 1000+ links per day and 500+ concurrent requests.
- Focused on cost-efficient serverless architecture with scalable event-driven processing.
